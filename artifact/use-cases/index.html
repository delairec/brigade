Trous et défauts

Un trou est une intention que ni le code ni une tâche ne satisfait, ou une étape que l'opérateur doit faire à la main alors que la CLI devrait l'enchaîner. Un défaut est un choix de conception ou de code plus faible qu'une alternative évidente. Chaque entrée cite sa preuve.
